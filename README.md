# Advanced Database Systems Portfolio

## Overview

This repository contains the practical portfolio developed for **MIT 8103: Advanced Database Systems**.

The project is based on the **Scholar Secondary School Academic Records System**, which manages student records, teachers, subjects, classes, academic terms, and assessment results.

## Portfolio Structure

```text
portfolio-1-database-design/
portfolio-2-query-optimisation/
portfolio-3-transactions-concurrency/
portfolio-4-nosql/
portfolio-5-distributed-cloud/
```

## Portfolio Components

### Portfolio 1: Database Design and Modelling
- Case study description
- Entity Relationship Diagram (ERD)
- Relational schema
- Keys and constraints
- Normalization (1NF, 2NF, 3NF)

### Portfolio 2: Query Processing and Optimisation
- SQL implementation
- Data population scripts
- JOIN queries
- Ranking and reporting queries
- Index creation

### Portfolio 3: Transactions and Concurrency
- COMMIT operations
- ROLLBACK operations
- Concurrency control discussion
- Transaction evidence

### Portfolio 4: NoSQL and Advanced Data Models
- MongoDB implementation
- Student document model
- NoSQL queries
- Model suitability analysis

### Portfolio 5: Distributed and Cloud Database Exercise
- Cloud database deployment proposal
- Replication architecture
- Sharding strategy
- Availability and scalability discussion
